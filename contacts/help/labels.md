## What labels are

Labels are colored, named tags you can apply to contacts. A contact can have any number of labels, and a label can be on any number of contacts.

Labels live in your **user_org** — they're shared across the contact list and any other package that uses labels (mail, for example). A label called "Clients" works the same way wherever it appears.

## Managing labels

Open the gear icon next to **Labels** in the sidebar. The label manager dialog opens with:

- The list of your labels with name and color swatch.
- **Add label** — name + color picker.
- Each row has **Edit** (rename / change color) and **Delete**.

Deleting a label removes it from every contact (and every other record in other packages) that had it assigned, but does **not** delete the records themselves.

## Assigning labels to a contact

Open the contact's detail screen. The labels area above the form shows currently-assigned labels. Click to open a picker — check the labels you want, uncheck the ones you don't. Changes commit immediately.

## Viewing contacts by label

Each label is a clickable row under **Labels** in the sidebar. Clicking shows only contacts assigned to that label, with the count next to the name.

The breadcrumb at the top of the list shows the active label name, so you know which view you're in.

## Cross-package labels

If you also have Mail installed, applying the "Clients" label to a contact and to a mail thread groups them together conceptually but **doesn't** create a link between them. Each record has its own assignment row. Label filters in Mail don't show contacts, and vice versa.
