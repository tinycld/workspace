## To create a document from a template

1. Open the text index page (the **Text** entry in the left rail).
2. Click **From template…** next to the **+ New document** button. The same action is in the text sidebar.
3. Pick one of the four cards:
   - **Blank** — an empty document. Identical to clicking **+ New document**.
   - **Letter** — sender and recipient address blocks, date, salutation, body, closing.
   - **Resume** — name as a heading, contact line, then Experience / Education / Skills sections with placeholder bullets.
   - **Report** — title, then Executive Summary / Background / Findings / Recommendations sections.

The template content is yours to edit immediately — the placeholder text (italicized for the date and date-range fields) is just a starting structure.

To start with a blank document, click **+ New document** directly — no picker required.
