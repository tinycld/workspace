## Opening a file

Click (or tap) any file to open it. What "open" means depends on the type:

- **Files with a custom opener** — e.g. a `.xlsx` opens in [Calc](help://calc:getting-started). The custom action appears as the default click target.
- **Files with a preview** — PDFs, images, video, audio, text and code files open in the [preview modal](help://drive:previews).
- **Everything else** — opens the file's info panel; download from there if you want the bytes.

You can also right-click → **Preview** for any previewable file, or **Open** for files that have a custom opener.

## File actions

Right-click any file (or use the toolbar when one is selected) for the full set of actions:

- **Preview** — open the in-app preview.
- **Open** — open with the package that handles this type (Calc for spreadsheets, etc.).
- **Download** — save the file to your device.
- **Share** — open the [share dialog](help://drive:sharing).
- **Rename** — change the file's name.
- **Move** — move to another folder.
- **Info** — open the [details panel](help://drive:files#details-panel).
- **Add star** / **Remove star** — mark as a favorite.
- **Upload new version** — replace the file's contents while keeping its identity, name, and share links. See [versions](help://drive:versions).
- **Move to trash** — soft-delete. See [Trash](help://drive:trash).

## Starring files

Click the star icon, or use the **Add star** / **Remove star** action. Starred files appear in the **Starred** section of the sidebar — a per-user list, so your stars don't affect what other people see.

## The details panel

The **Info** action (or clicking the (i) button in the toolbar with a file selected) opens a side panel with three tabs:

- **Details** — name, owner, size, type, created and modified timestamps, location, description.
- **Versions** — every prior version of the file, with timestamps and sizes. See [versions](help://drive:versions).
- **Activity** — recent changes to this file (renames, share changes, uploads).

The details tab is also where you can edit the file's **description** — a free-text field that's indexed for [search](help://drive:search).

## Downloading

**Download** saves the file's current version to your device. On web, it goes to your browser's Downloads folder. On iPad, the iOS share sheet opens so you can save to Files, AirDrop, etc.

To download a *prior* version instead of the current one, open the Info panel → Versions tab.
