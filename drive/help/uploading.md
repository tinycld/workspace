## Drag and drop

Drop files (or folders) anywhere on the Drive workspace. The whole pane highlights as a drop zone, and the upload begins as soon as you release. Dropping inside a folder uploads there; dropping at the root uploads into My Files.

You can drop:

- **Individual files** of any type — documents, spreadsheets, images, videos, audio, archives.
- **Multiple files** at once — they upload in parallel and progress is tracked individually.
- **Whole folders** — the folder structure is preserved, with empty folders skipped.

## The Upload button

Don't want to drag? Click the **New** button in the sidebar and choose **Upload**. A native file picker opens. On iPad, you can choose **Photos & videos** to grab directly from your Photos library, or **Files** to browse iCloud and other providers.

## Upload status

While uploads are in progress, a status bar pins to the bottom of the screen showing:

- How many files are uploading and how many are done.
- The current file's name and percentage.
- A retry button on any failed upload.

You can keep using Drive — even navigate to a different folder — while uploads continue in the background.

## Replacing a file vs adding a new one

If you upload a file with the same name as an existing file in the same folder, Drive doesn't overwrite. It appends a number to keep both:

- `Report.pdf` already exists → the new upload becomes `Report (1).pdf`.

To replace the contents of an existing file instead, right-click that file and choose **Upload new version**. The new bytes become the current version and the previous version is preserved in [version history](help://drive:versions).

## Storage quota

Each org has a storage quota. The sidebar's storage bar shows your usage. When you approach the quota, uploads are still allowed; once you exceed it, new uploads are rejected with an error. Free up space by emptying [Trash](help://drive:trash) — trashed files still count against the quota until permanently deleted.
